# PVdetection_YOLO8

Este proyecto tiene como objetivo la detección automática de módulos solares fotovoltaicos en techos utilizando imágenes satelitales y el model YOLOv8.

## 📁 Estructura del Repositorio
*   `Training.ipynb`: Cuaderno con el proceso de entrenamiento del modelo.
*   `evaluacion.ipynb`: Análisis de métricas de desempeño y resultados.

## 🚀 Tecnologías Utilizadas
*   **Lenguaje:** Python.
*   **Modelo:** YOLOv8 (Ultralytics).
*   **Entorno:** Lightning AI.

## 📊 Metodología
1. **Adquisición de Datos:** Uso de datasets de Roboflow.
2. **Preprocesamiento:** Ajuste de imágenes y anotaciones.
3. **Entrenamiento:** Implementación del modelo YOLOv8.
4. **Validación:** Evaluación de precisión y detección en escenarios reales.
